# EMBER

Запуск: дважды нажмите [Запустить сайт.cmd](Запустить%20сайт.cmd), либо выполните `node server.js`.

Откройте `http://localhost:8000`.

Администратор по умолчанию: логин `admin`, пароль `admin123`. Смените их перед публикацией.

База `ember.db` создаётся автоматически. В ней сохраняются пользователи, сессии, заказы и состояние столиков.

Меню также хранится в таблице `dishes` базы `ember.db` и создаётся/заполняется при первом запуске. Администратор может добавлять, редактировать, удалять и скрывать блюда, а также менять состояние «В наличии» / «Нет в наличии» в разделе «Меню» админ-панели. Сервер повторно проверяет наличие блюда при оформлении заказа.
